# 🌦 Weather App

A modern Flutter weather application with real-time forecast, dynamic UI, and animated background.

## ✨ Features

- 🔍 City search functionality
- 📍 Current location support
- 🌡 Real-time weather data (OpenWeather API)
- 🎨 Dynamic gradient based on weather
- 🌙 Auto Day/Night theme switch
- 💎 Glassmorphism UI design
- 🎬 Animated weather background (Lottie)
- 📊 Hourly forecast display
- 📱 Responsive design

## 🛠 Built With

- Flutter
- Dart
- OpenWeather API
- Geolocator
- Lottie Animations
